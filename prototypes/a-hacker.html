// first run

Three steps, then forget about it.

  1. enable accessibility

    Wispr Free uses it to find supported text fields and insert the draft you confirm. Password fields are skipped.

  2. pull a model

    Choose the one that fits your phone and languages. Switch later without reinstalling.

  3. tap the mic

    Android asks for mic access the first time. Tap ✓ to insert. If a field won't accept text, you get a Copy button instead.
